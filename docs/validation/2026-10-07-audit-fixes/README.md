## Changes

- A successful discussion reload replaces normalized root/child caches, refetches reachable expanded branches, and retains a reading anchor only if it still exists in the fresh result. Removed replies and branches cannot survive in the old cache. Late root/child and mutation responses from an older cache generation are discarded. The fresh exact-post ancestor path stays intact when its target is beyond the first sibling page.
- Authorization/visibility failures (401/403/404) discard the previously visible topic, its nodes and controls. Offline failures retain loaded content and expansion. A denied child request also invalidates the topic; root-page pagination errors use the same error handling. Local regressions cover removed children, a branch losing all children, reading-anchor retention/removal, offline cache retention and authorization/availability failures.
- Title Next transfers the UIKit first responder directly to the body instead of resigning the title first and initiating a keyboard-dismissal transition. The existing native journey verifies body newlines, continued typing, protected Cancel and Keep editing with restored typing.
- Added the base `UISupportedInterfaceOrientations` build setting alongside the existing device-specific keys and regenerated the project. The built plist previously had only `~iphone`/`~ipad` variants. The Arabic UI test now validates actual landscape window geometry and unchanged mixed Arabic/Latin text. Apple documents the [base orientation key](https://developer.apple.com/library/archive/qa/qa1588/_index.html).
- Catalogue search recovery now targets the native search dismissal control named Close or Cancel while excluding the composer's Cancel. Active search replaces the sheet navigation toolbar; the test exits search before closing the inserter. This is an automation correction, not a production workaround or weakened assertion. It still checks Photo/Quote, description search for Poll, hidden-keyboard/body preservation, quote insertion and exact Markdown.
