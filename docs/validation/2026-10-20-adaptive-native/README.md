## Implemented behavior

- Width and Dynamic Type determine one-pane reading, list/detail, and optional community sidebar. One NavigationSplitView owns the retained per-tab reading route; compact Back and same-topic reselection preserve the list/query. The native Duo system supplies its own chrome.
- A compact community selector replaces the tall feed header and category chips. One popover adapts to a sheet, retains filter/focus across presentation changes, keeps matching child ancestors, and uses the same typed scope as directory/sidebar. A failed catalog cannot masquerade as exhaustive no matches.
- Topic search starts collapsed on each searchable topic list. Pull at the top or magnifier reveals it; active input stays visible; Cancel restores the scoped feed. The local directory/chooser filter remains separate.
- Typed requests validate original terms using fetched search settings before adding trusted numeric category scope, reject unsupported operators, encode once, and validate exact post identity, topic joins, archetype and category boundaries. Grouped failures are decoded before result facets; failure cannot publish hits or metadata. Search HTTP cache reads and writes are disabled.
- A tab-owned search controller guards query/scope/viewer/locale/attempt identity, coalesces requests, keeps prior permitted rows on refresh/paging errors, and manually retries the failed operation/page. Cancellation is silent. Ambiguous 403 checks member session identity; 429 respects server deadlines or bounded fallback. No guest downgrade.
- New browsing/search UI has English and Arabic resources, semantic layout and a foreground-colored template wordmark for dark contrast. Discourse category names/content stay server-owned.
- C08 category fallback validates identity and explicit posting permission without treating a readable restricted category as inaccessible. Explicit public links/publication targets can leave an unrelated active scope, while ordinary scope changes preserve selected reading behind the outside-scope notice. Introduction links require the configured origin/base path and a supported topic destination.
