TECHNICAL ASSUMPTIONS
  • Native SwiftUI client; Discourse owns content, permissions, posting rules and moderation.
  • No base URL, plugins, credentials or API contract is assumed or shown.
  • Per-post can-like / can-reply and per-category can-create data exist; Like, Quote, Reply and chooser rows depend on it.
  • Links keep topic ID and post number separate from post ID.
  • Target is iOS 26 and later. Liquid Glass comes from standard SwiftUI TabView, NavigationStack toolbars, menus, sheets and .glass / .glassProminent button styles; the browser mockup only approximates it.
  • App text uses system text styles, so Dynamic Type scaling is native; the ~200% frames only simulate it.
  • Find communities filters the directory data already loaded; no server-side community search is assumed.
  • Photo upload progress, failure and retry are mock states; no endpoint, size limit or format is assumed.
  • Like, Save and Track after sign-in are restored but never applied automatically.
PROPOSALS, NOT ACCEPTED FACTS
  • Latest as the Home default; no other sort this pass.
  • Communities as a flat directory: letter tile, description, latest visible discussion, two subcommunities then “N more”. Whether Discourse supplies category logos and a per-category latest topic for this view is unconfirmed; the previews are illustrative.
  • Find communities as a local filter, with a hand-off to discussion Search on no match.
  • Upload progress and failure copy for the single photo attachment.
  • Fomio AMOLED dark theme from the web tokens.
  • Global Create chooses a community first; only postable communities are listed.
  • Full-height sheet composer on iPhone; form sheet on iPad.
  • Pending-review notice on the origin screen, dismissable, no promised location.
  • Like counts hidden on feed rows; shown in discussions.
  • iPad tab bar adapts to a sidebar at regular width.
OPEN DECISIONS
  • Draft storage: device, account or both; sign-out retention. No screen claims sync.
  • How Discourse signals a queued post and whether the author sees it.
  • Reconciliation method after no response; no idempotency assumed.
  • Sign-in mechanism and account creation.
  • Reply presentation stays chronological; nested is not drawn.
  • Whether a draft stays listed while its post is pending.
DEFERRED, NOT SHOWN
  • Private messages and chat
  • Activity, account and notification settings
  • Hot, Tracked, filters, notification levels
  • Editor modes, formatting and advanced tools, editing posts
  • AI features
